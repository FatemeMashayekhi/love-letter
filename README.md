# 💌 Interactive Love Letter

A small interactive web project built with **React** and **Framer Motion**.

The project features a closed envelope that opens when clicked, revealing a letter with a romantic message through smooth animations and 3D transformations.

## ✨ Features

- Interactive envelope animation
- 3D envelope flap opening
- Letter reveal animation
- Smooth transitions powered by Framer Motion
- Simple and clean React structure
- Responsive layout

## 🛠️ Built With

- **React**
- **Vite**
- **Framer Motion**
- **CSS**

## 🎨 Animation

The envelope uses **Framer Motion** to control the opening interaction.

The animation combines:

- `rotateX` for the envelope flap
- `translateY` for the letter movement
- `opacity` for the message reveal
- CSS `perspective` for the 3D effect
- CSS `clip-path` for creating the envelope shape

## 💌 Concept

The goal of this project is to create a simple but delightful interaction where a digital envelope behaves like a real one: click it, open it, and reveal the message inside.
